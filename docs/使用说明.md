# 使用说明

## 一、两种目标

| 目标 | 适用 | 命令 |
| --- | --- | --- |
| `.cube`（S-Log3 域创意外观变换） | 官方 look LUT、自制的观感 cube | `--target X.cube`（`--gamut` 选对：S-Gamut3 / S-Gamut3.Cine） |
| 色卡同尺寸 TIFF/JPG（11648×8736） | 把创意外观渲染到参考色卡上导出的图 | `--target-image X.tiff` |

TIFF/JPG 要求：与 v4.5 色卡同尺寸、保留方向、不缩放不裁切、RGB（sRGB 或 RGB ICC）。

## 二、命令

```bat
:: 资产检查
py -3 -m r5lut verify

:: 正式转换(默认:120 评估/12 起点 + PC + 网格 + 诊断)
py -3 -m r5lut convert --target "FL.cube" --number 1 --name FL --full-name "FL 创意外观" -o out\r5-fl

:: 草稿(快速拟合,不带 PC/网格,产物是合法 BIN)
py -3 -m r5lut convert --target "FL.cube" --number 1 --name FL --full-name "FL 创意外观" -o out\r5-fl --quick

:: 分步参数版
py -3 -m r5lut train --target "FL.cube" --number 1 --name FL --full-name "FL 创意外观" ^
    -o out\r5-fl --evaluations 120 --starts 12 --pc --grid

:: 读回 BIN / 重新打包 / 看进度
py -3 -m r5lut inspect out\r5-fl\R5NATIVE.BIN
py -3 -m r5lut compile out\r5-fl\native_config.json -o out\r5-fl\R5NATIVE.BIN
py -3 -m r5lut status out\r5-fl

:: 批量(列表 JSON,串行)
py -3 -m r5lut batch 列表.json -o out\batch
```

列表 JSON 格式：

```json
[{"target": "C:/.../FL.cube", "number": 1, "short": "FL", "full": "FL 创意外观"}]
```

## 三、颜色预览

界面上半部是「颜色预览」：选好目标 `.cube` 后自动生成

- **原图**：色相带 + 11 级灰阶 + 肤色/原色块
- **套用 LUT 后**：同一个 cube 作用在 sRGB 显示值上的效果（与剪辑软件里一致）
- **色块对照**：每个色块左边原色、右边套用后颜色
- **点图上任意位置**：状态栏显示该点 原图 RGB → 套用后 RGB
- **载入图…**：用你自己的 PNG 替换测试图；**保存预览**：导出 PNG

> 预览是 cube 在 sRGB 上的直接观感，用来选片/核对风格；训练按官方方法在
> S-Log3 域解释同一个 cube，最终效果以机内实拍和 `diagnostics.json` 为准。

## 四、GPU 加速

```bat
set R5_GPU_TRAINING=1
```

- 需要 CUDA 版 torch：`pip install torch --index-url https://mirrors.aliyun.com/pytorch-wheels/cu124`
- 只加速浮点拟合；PC/网格/整数评估仍走 CPU
- 实测 quick 档 11–12 分钟（CPU）→ 3.2 分钟（RTX 4060）

## 五、输出目录

| 文件 | 说明 |
| --- | --- |
| `native_config.json` | 固件 JSON 格式（见 JSON格式说明.md） |
| `R5NATIVE.BIN` | 固件二进制（2580 字节，魔数 `R5CUST4\0`） |
| `v4-config.zip` | 交付包（BIN + JSON + export_audit），正式档才有 |
| `diagnostics.json` | 独立 test 集指标（`tonal` 是网格档成品成绩） |
| `fit/recipe.json` | 拟合过程审计 |

## 六、上机

1. 取 `R5NATIVE.BIN`（或 `v4-config.zip` 内的）
2. 按固件 release 说明放到 SD 卡导入（整包替换）
3. 机内选槽位（1–12）→ 拍参考图验收

注意：BIN 只含整数参数 + 网格，响应模型不写入固件；离线指标 ≠ 机内成像，
最终以实机为准。

## 七、故障排查

| 现象 | 处理 |
| --- | --- |
| `训练引擎缺失` | `engine/` 不在 exe 同级；设 `R5_ENGINE_ROOT` 指向它 |
| `需要系统 Python` | 打包版需要 `py -3`；设 `R5_PYTHON` 指定解释器 |
| `Gamma must be monotone` | 拟合末端超过原生端点；工具已自动取 `max(原生端点, 拟合末端)` |
| 内存不足 | 网格阶段峰值 16–18GB；关掉其它任务、单任务串行 |
| torch 不可用 | 自动禁用 gamma_global_correction 阶段；装 CUDA torch 并设 `R5_GPU_TRAINING=1` |
