# 训练方法（官方方法，sRGB 路径）

来源：[sony-a7r5-custom-firmware](https://github.com/Hearts-Ace/sony-a7r5-custom-firmware)
的官方训练台 [sony-r5-colorlab](https://github.com/Hearts-Ace/sony-r5-colorlab)（AGPL-3.0，
vendored 在 `engine/`）。本工程把它的管线封装成"cube/TIFF → 固件滤镜"一条命令。

## 管线

```
目标（.cube 或色卡同尺寸 TIFF/JPG）
  ↓ prepare   99,372 个色卡色块经 RawSLog3Reference(sensor→WB→相机矩阵→S-Log3→cube→clip)
              投影成目标色；TIFF 走 ICC 浮点转 sRGB、中心横向 5 点均值，无 8bit 中间量化
  ↓ fit       连续松弛初始化 → 整数参数评估（CC1/block13/Gamma，单调凹约束）
              → 多起点选择（uint8 RGB MSE + 0.35·(2.55·ΔE00)²）→ 整数舍入 refine
  ↓ finish    量化 → native_config.json + R5NATIVE.BIN
  ↓ 诊断      独立 test 集 8bit MAE/RMSE/p95 与 ΔE00（阴影/中间调/高光分组）
```

PC 补偿与网格蒸馏（`convert` 默认开启，`train --pc --grid` 单独控制）：

- `--pc`：在原生参数上再拟合残差（明暗曲线 + 灰阶染色 + 灰阶保护色网格）
- `--grid`：把冻结的 PC 变换蒸馏成固件消费的 3×5×9×9 signed7 网格，打包 `v4-config.zip`

## 关键身份（任何一项不符拒绝训练）

| 资产 | 约束 |
| --- | --- |
| Hybrid 响应模型 | `r5-paired-20261107-nonlinear-he3`，sha256 `936af0b2…e677` |
| v4.5 雷霆大色卡 | 5300K 一亿像素合成色卡（99,372 色块），pairs.npz 与 manifest 哈希 |

## 预算与耗时（16C/32T + RTX 4060 实测）

| 档 | 说明 | 单任务耗时 |
| --- | --- | --- |
| `--quick`（草稿） | 1 评估/2 起点，**不带** PC/网格 | GPU ~3.2 分钟 / CPU ~11–12 分钟 |
| **`--budget balanced` + `--aim N`（推荐）** | 40 评估/6 起点，验证集 mae8 ≤ N 即提前停止 | **GPU ~15 分钟** |
| 默认（正式） | 120 评估/12 起点 + PC + 网格 + 诊断 | GPU 约 50–60 分钟 / CPU 约 5 小时 |

### 目标驱动早停（`--aim`）

`R5_STOP_MAE8`（CLI/GUI 的 `--aim`/「目标 mae8」）让拟合在**验证集 mae8 达标后
立刻停止**：跳过剩余自适应轮次，达标时再跳过后续 Gamma 阶段。引擎仍做整数
量化、PC 补偿与网格蒸馏，所以产物仍是完整交付包。

实测（同目标、GPU、带 PC+网格）：

| 目标 | 正式档 120/12 | 平衡档 40/6 + aim | 加速 | 最终 mae8 变化 |
| --- | --- | --- | --- | --- |
| Q Classic | 57 分钟 / mae8 4.02 | **14.9 分钟 / 3.08** | 3.8x | 更好 |
| Portra 400 | 37 分钟 / 7.01 | **14.3 分钟 / 6.58** | 2.6x | 更好 |
| Movus V6 | 55 分钟 / 16.25 | **15.1 分钟 / 15.66** | 3.6x | 略好 |

> 注意：`aim` 比对的是**验证集**指标（开着 `--pc` 时含 PC 补偿），与最终网格档
> test 指标不一定相同——像 Portrait/Movus 这类离原生较远的观感，网格压缩会有
> 折损。质量以 `diagnostics.json` 的 `tonal`（网格档）为准。

- GPU：`set R5_GPU_TRAINING=1`（torch CUDA/Metal）；只加速浮点拟合阶段，
  整数评估/PC/网格蒸馏仍走 CPU
- 多任务建议串行（并发争抢反而更慢）；网格蒸馏内存峰值 16–18 GB，32 GB 机器必须串行
- 颜色空间：sRGB（cube 输出 clip 到 [0,1]，指标按 8bit sRGB；不声称跨光源等价）
